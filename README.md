# probability-notes

我啃《概率论与数理统计》的笔记。一章一个文件，先按这门课通用的顺序写一版，再拿讲义对着改——对不上的地方划出来重写。

## 为什么长这样

我读不了 PDF（接口只吃网页和图片，图还看运气），所以这仓库不是「照着讲义抄」，是「先按自己的理解写一版，再回头纠」。纠错比从零讲省事。

## 每章怎么写

每个 md 固定这几段：

- **本章在干嘛**：一句话说清这章解决什么问题
- **定义与定理**：只留会用的，证明过程长的不抄
- **公式**：能直接代数的（分布、期望、方差、密度函数）
- **典型例题**：3~5 道，从套公式到需要绕一步的
- **易错点**：我自己容易混的地方，也标出来

## 约定

- 讲义页码 / 小节名写在每章开头，方便对照
- 写错了直接开 issue 或者当面说，不用客气
- 有争议的写法（比如「密度函数是不是概率」这种）单列一条，别混在正文里
